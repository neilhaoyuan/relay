# Relay file and directory map

This document inventories the rebuild. Every handwritten application module begins with a short purpose comment. Existing historical files are identified separately. Generated package contents and compiler output are documented by their generating directory rather than repeating third-party inventories.

## Directories

| Directory | Purpose |
| --- | --- |
| Repository root | npm workspace coordination, environment examples, ignore rules, and the entry-point README. |
| `server/` | Trusted Node.js application. Runs on the Docker host, owns persistent state and infrastructure. |
| `server/src/` | Backend source modules described below. |
| `web/` | Browser application built by Vite. |
| `web/src/` | Browser IDE, API client, and visual styling. |
| `packages/` | Small shared packages used by both applications. New in this rebuild. |
| `packages/contracts/` | Type-only API contracts, independent of Node, Docker, and browser implementation. New. |
| `infrastructure/` | Linux container image and service supervisor definition. New. |
| `tests/` | Repeatable integration and browser acceptance checks. New. |
| `docs/` | Project documentation; existing directory, now included by Git. |

## Root files

| File | What it does |
| --- | --- |
| `README.md` | Replaced the placeholder with setup commands, workflows, verification, current limits, and documentation links. |
| `package.json` | Registers server, web, and contracts workspaces. Provides build/start/check/test commands, specifies Node compatibility, and declares the Playwright test dependency. |
| `package-lock.json` | Locks the exact installed dependency graph for reproducible `npm ci` installations. Generated by npm. |
| `.gitignore` | Excludes credentials, runtime data, old-code backups, test artifacts, dependency caches, and compiled output. Removes the previous blanket ignore of documentation. |
| `.env.example` | Documents host, port, data directory, image, resource limits, task timeout, public origin, and optional owner token. Copy to ignored `.env`. New. |

## Backend files

| File | What it does |
| --- | --- |
| `server/package.json` | Server scripts and dependencies: contracts, WebSockets, and the terminal PTY library. |
| `server/tsconfig.json` | Existing strict TypeScript configuration, producing native Node ESM in `server/dist/`. |
| `server/src/index.ts` | Replaces the old PTY-only server. Wires services together, serves the browser build, validates JSON requests, exposes the API, authenticates WebSockets, and manages startup/shutdown. |
| `server/src/config.ts` | Reads and validates configuration; detects host CPU/RAM and defines defaults. New. |
| `server/src/store.ts` | Opens SQLite in WAL mode, initializes its schema, stores typed records, persists ordered events, and emits changes only after writes finish. New. |
| `server/src/process.ts` | Runs Git and Docker as argument arrays with timeouts and bounded output; never constructs shell commands from user strings. New. |
| `server/src/files.ts` | Imports repositories, creates fresh projects, lists/reads/saves source files, prevents path escapes, makes snapshots, calculates source fingerprints, generates binary-capable Git patches, and applies changes. New. |
| `server/src/runtime.ts` | The Docker lifecycle adapter: inspect/start/stop/remove/pause, resource-limited containers, scoped mounts, and Codex/terminal command construction. New. |
| `server/src/codex.ts` | Implements newline-delimited app-server JSON-RPC: initialization, request IDs/timeouts, notifications, approval responses, and transport shutdown. New. |
| `server/src/orchestrator.ts` | Coordinates imports, workspace lifecycle, snapshots, the FIFO run queue, resource admission, approvals, cancellation, retained history, proposal application, and restart reconciliation. New. |
| `server/src/auth.ts` | Generates/loads the owner's access token, verifies login attempts, signs and validates session cookies, and validates browser origins. New. |
| `server/src/terminal.ts` | Owns Docker shell PTYs separately from browser connections; maintains bounded scrollback and reconnectable terminal sessions. New. |

## Browser files

| File | What it does |
| --- | --- |
| `web/package.json` | Browser scripts and dependencies, including CodeMirror, language support, xterm, Vite, and shared contracts. |
| `web/tsconfig.json` | Existing strict browser TypeScript checking with DOM types and bundler resolution. |
| `web/index.html` | Replaces the terminal-only page with login, workspace navigation, explorer, file tabs, editor, terminal, agent panel, history, and dialogs. |
| `web/src/main.ts` | Connects UI actions to the backend; manages workspace/file selection, unsaved changes, task submissions, event catch-up, approvals, experiments, parallel tasks, review, and terminal attachment. Rebuilt. |
| `web/src/api.ts` | Small authenticated same-origin fetch wrapper and WebSocket URL builder. New. |
| `web/src/editor.ts` | Configures CodeMirror with language highlighting, search, history, line numbers, editing, and save shortcuts. New. |
| `web/src/style.css` | Replaces the terminal styling with the responsive dark IDE layout, mint accents, dialogs, and accessible control states. |

## Contracts, deployment, tests, and documentation

| File | What it does |
| --- | --- |
| `packages/contracts/package.json` | Declares the type-only `@relay/contracts` workspace. New. |
| `packages/contracts/index.d.ts` | Shared shapes for workspaces, task states, events, files, proposals, and server capacity. New. |
| `infrastructure/Dockerfile.workspace` | Builds the Node.js/TypeScript execution image with Git, Bash, compilation tools, and pinned Codex 0.160.0. Uses a non-root default user. New. |

| `docs/FILE_MAP.md` | This inventory; the requested explanation of every application/configuration file and directory. New. |
| `docs/ARCHITECTURE.md` | Records the agreed first scope, module boundaries, lifecycle rules, trust assumptions, and limitations. New. |
| `docs/VM_SETUP.md` | Documents deployment, daily use, acceptance checks, service operation, and backup procedure. New. |
| `docs/PROJECT_SPEC.md` | Pre-existing design for the old terminal prototype. Retained, not rewritten. |
| `docs/test.md` | Pre-existing scratch document. Retained, not rewritten. |

## Generated and private directories

| Path | Contents and purpose |
| --- | --- |
| `.relay-backup/` | Ignored pre-rebuild copies of the four existing modified files, preserved before replacing them. |
| `.relay-backup/server-index.ts` | Original modified server entry point. |
| `.relay-backup/web-main.ts` | Original modified browser terminal controller. |
| `.relay-backup/web-style.css` | Original modified terminal styling. |
| `.relay-backup/web-index.html` | Original modified terminal page. |
| `.relay-data/` | Default private persistent data directory; use `/var/lib/relay` on the VM. Never commit it. |
| `.relay-data/relay.db`, `relay.db-wal`, `relay.db-shm` | SQLite database and its journaling/shared-memory files. |
| `.relay-data/access-token` | Generated owner login secret when no token environment variable is supplied. |
| `.relay-data/workspaces/<id>/source/` | A workspace's persistent project files and independent Git repository. |
| `.relay-data/workspaces/<id>/index-*` | Short-lived alternate Git index used for reviewing changes without altering the working index; removed after use. |
| `.relay-data/codex/` | Shared Codex authentication, settings, and persistent session history. Each workspace uses a separate thread ID. |
| `.test-data/` | Ignored temporary test databases, repositories, screenshots, and protocol reference output. |
| `.test-data/codex-protocol/` | TypeScript protocol bindings generated by local Codex 0.160.0 for reference. Each generated file describes its named RPC request, response, or data type; these are not shipped. |
| `.test-data/codex-home/` | Empty/temporary Codex configuration used to inspect CLI capabilities without using the owner's login. |
| `.test-data/core-*`, `.test-data/events-*`, `.test-data/browser-*` | Isolated test workspaces, normally deleted by test teardown. |
| `.test-data/relay-ide.png`, `.test-data/relay-mobile.png` | Desktop and mobile browser acceptance screenshots. |
| `.npm-cache/` | Local npm download cache and package installation diagnostics. |
| `node_modules/` | Installed dependencies and npm workspace links. |
| `server/dist/` | Compiled backend JavaScript, generated by `tsc`. |
| `web/dist/` | Browser HTML and bundled CSS/JavaScript, generated by Vite. |
